# WarPawns_TemplateScenario

Copy this folder into `Documents/War Pawns/Mods/`, then replace IDs, map coordinates, unit ids, text keys, and images.

This template demonstrates:

- standalone `.scenario` mod structure;
- popup thumbnail from `images/popup_thumbnail.png`;
- `RoundStarted` trigger;
- `UnitMoved` trigger with `AnyUnitMatches`;
- `spawn_units` command;
- `give_resources` command;
- win condition: no living enemy units remain.

Important: verify all hex coordinates and unitDataId values against your actual map and faction configs.
