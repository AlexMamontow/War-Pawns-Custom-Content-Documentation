# Reference

These files are lookup tables for values used in `.scenario`, `.campaign`, and `manifest.json` files.

| File | Contains |
| --- | --- |
| [BUILT_IN_MAPS.md](BUILT_IN_MAPS.md) | Built-in map IDs and camouflage profiles |
| [COORDINATES.md](COORDINATES.md) | Cube coordinate rules and standard coordinate CSV notes |
| [standard_map_coordinates.csv](standard_map_coordinates.csv) | All standard map coordinates |
| [ENUMS.md](ENUMS.md) | teamId, nationId, UnitType and other enum values |
| [UNITS.md](UNITS.md) | unitDataId by nation |
| [TRAITS.md](TRAITS.md) | traitId list |
| [UNIT_ACTIONS.md](UNIT_ACTIONS.md) | Unit action IDs, not scenario actions |
| [PAYLOADS.md](PAYLOADS.md) | Payload fields for scenario commands |
| [SCENARIO_REFERENCE.md](SCENARIO_REFERENCE.md) | Triggers, conditions, scenario actions, commands, selectors |
