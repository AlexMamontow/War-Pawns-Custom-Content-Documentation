# Publishing checklist

Before publishing or updating a Workshop item, check:

- [ ] The mod appears in the `Mods` screen.
- [ ] Status is `Valid`.
- [ ] The mod starts from `Custom Scenarios` or `Custom Campaigns`.
- [ ] The title and description are localized correctly.
- [ ] No raw localization keys are visible.
- [ ] Preview image appears or the fallback placeholder is acceptable.
- [ ] Popups work.
- [ ] Popup thumbnails load.
- [ ] Win and lose conditions work.
- [ ] Campaign missions unlock correctly, if this is a campaign.
- [ ] Temporary test win conditions were removed.
- [ ] `workshopId` is empty for first publish, or set for update.
