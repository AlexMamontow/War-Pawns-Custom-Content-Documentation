# War Pawns Custom Content

This repository contains documentation and starter templates for War Pawns custom scenarios and custom campaigns.

## Quick start

1. Copy a template folder from `templates/` into:

```text
Documents/War Pawns/Mods/
```

2. Rename the mod folder and edit `manifest.json`.
3. Edit `.scenario` or `.campaign` files.
4. Start the game and open the Mods screen to validate and publish/update the mod.
