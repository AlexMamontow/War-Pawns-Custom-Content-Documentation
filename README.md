# War Pawns Custom Content Documentation and Templates

This repository package contains:

- `WarPawns_Custom_Content_Documentation.docx` — formatted documentation;
- `WarPawns_Custom_Content_Documentation.md` — Markdown copy for GitHub;
- `Templates/WarPawns_TemplateScenario` — standalone scenario template;
- `Templates/WarPawns_TemplateCampaign` — two-mission campaign template.

Copy a template folder into `Documents/War Pawns/Mods/` and edit IDs, coordinates, unit ids, localization, and images.
